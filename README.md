# Computer Networks Lab

A collection of **Computer Networks laboratory programs** implemented in **C++**. This repository contains practical experiments, algorithms, and implementations commonly performed in engineering Computer Networks labs. Each program is written with simple, well-commented code to help students understand the underlying concepts.

## 📚 Topics Covered

* Bit Stuffing
* Byte Stuffing
* Cyclic Redundancy Check (CRC)
* Checksum
* Hamming Code
* Stop-and-Wait ARQ
* Go-Back-N ARQ
* Selective Repeat ARQ
* Distance Vector Routing
* Link State Routing
* Other Computer Networks laboratory programs

## 🎯 Objectives

* Understand fundamental Computer Networks concepts.
* Learn the implementation of networking algorithms in C++.
* Practice laboratory experiments for university courses.
* Prepare for practical exams, viva, and interviews.

## 🛠️ Technologies Used

* **Language:** C++
* **Compiler:** GCC / G++
* **Platform:** Linux / Windows

## 🚀 How to Run

1. Clone the repository:

   ```bash
   git clone https://github.com/<your-username>/computer-networks-lab.git
   ```

2. Move into the project directory:

   ```bash
   cd computer-networks-lab
   ```

3. Compile a program:

   ```bash
   g++ program_name.cpp -o program
   ```

4. Run the executable:

   ```bash
   ./program
   ```
